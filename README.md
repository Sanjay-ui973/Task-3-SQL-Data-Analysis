# Task 3: SQL for Data Analysis

## Project Overview

This project demonstrates how SQL can be used to extract, manipulate, and analyze Ecommerce data.

## Objective

To practice SQL queries and analyze customers, products, and orders.

## Tools Used

* MySQL Workbench
* SQL
* GitHub

## Database Tables

1. Customers
2. Products
3. Orders
4. Order_Items

## SQL Concepts Covered

* SELECT, WHERE, ORDER BY
* GROUP BY and HAVING
* Aggregate functions: SUM(), AVG(), COUNT()
* INNER JOIN, LEFT JOIN, RIGHT JOIN
* Subqueries
* Views
* Indexes and query optimization using EXPLAIN

## Analysis Performed

* Filtered orders by amount and date
* Calculated total revenue and average order value
* Analyzed customer order counts and spending
* Combined customer, order, and product information using joins
* Identified orders above the average order amount

## Project File

* `ecommerce_task3.sql` — SQL queries

## Conclusion

This project helped me practice SQL techniques for Ecommerce data analysis and develop skills relevant to an entry-level Data Analyst role.
